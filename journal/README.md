# journal — прибор «вход → вердикт доски → факт»

Схема записи — карта, **§3.13**; инварианты **37** и **38** объясняют, почему
запись неизменяема. Здесь схемы нет и не будет: ТЗ архивируется, карта
остаётся. Ничего из журнала не отображается и ни во что не подаётся;
`index.html` и `main.py` он не трогает.

`write.js` вырезает единственный `<script>` из `index.html`, исполняет его в
`vm` и **вызывает продакшн-функции по имени** (инв. 21). Второй реализации
правила, порога или формулы здесь нет: `GIST_URL`, `STALE_CRIT_MIN`,
`CAT_WINDOW_D`, `TIER_MIN`, `CATALYSTS`, `tokens[]` читаются из того же
контекста, и переименование любого из них роняет журнал громко. Цены — только
зеркало `data-api.binance.vision`: боевые хосты Binance отвечают 451 из
Actions (инв. 24). Новых обращений к CoinGecko нет, триггер бота не затронут.

| Путь | Пишется | Что внутри |
|---|---|---|
| `data/YYYY-MM-DD.jsonl` | раз на дату | `k:"s"` на покрытую монету, `k:"x"` на непокрытую |
| `out/YYYY-MM-DD-h7.jsonl`, `…-h14.jsonl` | раз на дату × горизонт | `k:"oh"` заголовок BTC, затем `k:"o"` |
| `runs.jsonl` | дозапись на прогон | `k:"r"` прогон, `k:"g"` подписанный пробел |

Файлы `data/` и `out/` создаются через `link()` и **падают на существующем
пути**: неизменяемость физическая, а не обещанная. Дозаписывается только
`runs.jsonl`.

```
node journal/write.js --probe      # доступность и форма источников, не пишет ничего
node journal/write.js --dry-run    # весь конвейер во временный каталог, печатает запись
node journal/write.js --snapshot   # снимок дня + подписи пробелов
node journal/write.js --resolve    # созревшие исходы, не более 4 за прогон
node journal/write.js              # снимок + исходы — это и гоняет workflow
node bench/journal_bench.js        # офлайновый стенд, сеть не нужна
```

Прогон, не записавший данные, возвращает ненулевой код и печатает одну
grep-пригодную строку `JOURNAL … generated_at=…` (инв. 37). Две величины схема
не задаёт, они выведены здесь: `oh.btc.p0` — открытие первой часовой свечи окна
(BTC нет в `tokens[]`, строки снимка у него нет); `oh.asof` — конец окна,
срезанный до часа, а не время разрешения, иначе файл исхода перестал бы быть
воспроизводимым.
